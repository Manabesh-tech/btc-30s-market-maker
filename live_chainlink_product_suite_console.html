Model 1

Current Deployed Baseline

Basis-aware production model. `30s` and `1m` are basis-gated microstructure products. Longer tenors use the currently selected best live rule per product.

  • `30s` and `1m`: basis/dislocation first, direction second
  • `3m+`: product-specific best production rule
  • Current deployed model across products unless changed later
Model 2

Smoothed MR Variant

Keeps `30s` and `1m` unchanged, then replaces `3m+` with smoothed mean-reversion ladders. Weak and noisy buckets are flattened toward `50/50`.

  • Short tenors stay on Model 1 logic
  • `3m+` switch to capped MR ladders
  • Useful when you think MR will reassert itself next week
Model 3

Fixed-Window Chainlink MR

Chainlink-only ladder architecture for `3m+`: `2m` lookback on `3m/5m/15m`, and `20m` lookback on `1h`, all quoted from smoothed MR ladders.

  • `3m`, `5m`, `15m`: Chainlink `120s` move
  • `1h`: Chainlink `1200s` move
  • Clean, stable, easier to explain than many product-specific windows
